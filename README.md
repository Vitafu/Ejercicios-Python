# 🐍 Retos de Programación con Python

Repositorio personal donde recopilo mis soluciones a los **101 retos de programación de MoureDev**, publicados en [retosdeprogramacion.com](https://retosdeprogramacion.com/ejercicios/).

El objetivo de este proyecto es mejorar mis habilidades de programación, reforzar los fundamentos de Python y desarrollar la lógica necesaria para resolver diferentes problemas mediante código.

## 🎯 Objetivos

- Mejorar la lógica y el pensamiento computacional.
- Practicar la sintaxis y las funcionalidades de Python.
- Aprender a resolver problemas de diferentes niveles de dificultad.
- Trabajar con estructuras de datos, algoritmos y funciones.
- Mejorar la legibilidad, organización y eficiencia del código.
- Mantener un registro de mi progreso como desarrollador.

## 📚 Contenido

Los ejercicios están organizados siguiendo la numeración original de los retos.

| Dificultad | Descripción                                                      |
| ---------- | ---------------------------------------------------------------- |
| 🟢 Fácil   | Ejercicios para practicar conceptos básicos de programación.     |
| 🟡 Medio   | Problemas que requieren aplicar diferentes conceptos y técnicas. |
| 🔴 Difícil | Retos que necesitan un razonamiento y una lógica más avanzados.  |

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Python 3
- **Editor:** Visual Studio Code
- **Control de versiones:** Git y GitHub
